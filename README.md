# [www.rnt.com.np](https://www.rnt.com.np)

Personal engineering portfolio and project showcase for **Ram Narayan Thakur** — Flutter Developer & Mobile App Engineer based in Lalitpur, Nepal.

Built with **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS v4**, and **shadcn/ui**, inspired by the viral minimal design of `chanhdai.com` and `wizaye/portfolio`.

---

## 🚀 Highlights & Features

- **Mobile First & Responsive**: High-performance layout with light & dark theme detection.
- **Flutter & Mobile Specialization**: Highlighted production applications including [Bandobasta on Google Play](https://play.google.com/store/apps/details?id=com.bandobasta.bandobasta) and [Apple App Store](https://apps.apple.com/us/app/bandobasta/id6751802666).
- **Interactive Tech Stack**: Categorized mobile, cloud, backend, and frontend skill chips with official vector icons.
- **Experience & Education Timelines**: Expandable cards for professional roles at Bandobasta Pvt. Ltd and Computer Engineering degree from NCIT.
- **Live GitHub Activity Graph**: Real-time contribution heatmap connected to [@rn-byte](https://github.com/rn-byte).
- **Spam Protected Contact & vCard**: Base64 obfuscated contact triggers and one-click contact vCard download.
- **SEO & AI Ready**: Structured JSON-LD schema, OpenGraph tags, sitemap, robots, and `/llms.txt`.

## 💻 Local Development

1. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   # or
   pnpm install
   # or
   bun install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploy to Vercel

1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete portfolio redesign to Next.js 15 and Tailwind v4"
   git push origin master
   ```

2. Import the repository in [Vercel](https://vercel.com).
3. Under **Project Settings > Domains**, add your custom domain: `www.rnt.com.np`.
4. Vercel automatically detects Next.js 15 and sets up SSL and global CDN edge routing.
